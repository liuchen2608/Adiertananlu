# 阿迪尔探案录

**历史悬疑推理小说 · 连载试写版**

1799年，法国鲁昂。一个被世人认定已经死亡的旧贵族青年，隐姓埋名，以私人调查谋生。他叫阿迪尔，也使用“莫兰”这个名字。

他不断追查别人的秘密，却始终无法解开自己人生中最大的谜团：妹妹为何死于那场针对家族的袭击，以及父亲究竟隐瞒了什么。

## 第一案：《死者的最后一封信》

一位布匹商人死在自己的书房，现场似乎指向服药自杀。然而邻居、仆人和一份深夜商业记录，都声称他在不同时间仍然活着。阿迪尔必须从证词与物证中辨别事实，重新审视这场死亡。
